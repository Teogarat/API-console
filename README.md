# iiko API Console

Статическая консоль запросов iiko Cloud, Yandex Eda и Magnit. Приложение находится в `index.html` и работает без сборки. HTTP-запросы отправляются через выбранный пользователем Proxy Worker.

## Обновление iiko API — 5 ноября 2026

Каталог построен по [официальной OpenAPI iiko](https://api-ru.iiko.services/api-docs/docs): **416 операций текущей спецификации** и **2 исторических метода** для проверки совместимости. Из 416 операций 68 помечены самой спецификацией как устаревшие. По умолчанию интерфейс показывает 348 актуальных методов; переключатель «Все, включая устаревшие» открывает весь каталог из 418 записей.

Для каждого запроса доступны метод, точный путь, описание, JSON-шаблон и сведения об обязательных полях. Примеры построены по актуальным схемам, включая вложенные объекты и конкретные типы полиморфных запросов. Перед отправкой нужно заполнить реальные ID, даты, фильтры и другие бизнес-параметры.

### Внешнее меню v3

Основная кнопка загрузки меню использует `POST /api/menu/v3/by_id`:

```json
{
  "externalMenuId": "ID выбранного меню",
  "organizationId": "ID выбранной организации",
  "priceCategoryId": null
}
```

Список внешних меню загружается прежним `POST /api/2/menu`. Авторизация использует `POST /api/v2/access_token`. Версии остальных путей определяет спецификация каждого метода: общего переименования `/api/1` в `/api/v2` нет.

Ответ v3 преобразуется из `products`, `modifiers` и `itemsGroups` в модель интерфейса. Разные размещения одного продукта сохраняют свои цены, размеры и модификаторы. В заказ передаются реальные `productId`, `productSizeId` и `productGroupId`, а внутренние ключи интерфейса в API не уходят. При смене организации очищаются старое меню и корзина; запоздавший ответ загрузки не заменяет меню новой организации.

Правила обработки данных:

- `0` остаётся нулевой ценой, `null` — неизвестной ценой. Позиции без цены нельзя отправить через конструктор заказа.
- Nullable-переопределения модификаторов наследуются из справочника; явные `false`, `0` и пустые строки сохраняются.
- Цена модификатора выбирается по совпадающему `sizeId`. Если подходящей цены нет, интерфейс показывает отсутствие цены; недокументированный выбор цены другого размера не выполняется.
- Конструктор формирует обычные позиции `Product`. Для `Compound` требуется собственное тело запроса в редакторе; такое блюдо не преобразуется автоматически в `Product`.

В редакторе остаётся старый `/api/2/menu/by_id` с пометкой об устаревании и ссылкой на новый маршрут. Исторические `/api/1/nomenclature` и `/api/1/access_token` отсутствуют в опубликованной OpenAPI. Это не означает подтверждённое отключение на сервере; их доступность не проверялась.

Описание перехода: [официальное руководство по внешнему меню](https://api.iiko.help/docs/en/guides/external-menu/).

## Запуск

Открой `index.html` в браузере или размести файл на статическом хостинге. Выбери Proxy Worker, укажи данные подключения и нажми Connect. Для нового меню выбери организацию, внешнее меню и при необходимости ценовую категорию.

Для поддерживающего разные маршруты прокси смена версии меню не требует отдельного перенаправления: путь передаётся в существующем параметре `path`.

## Обновление каталога

Нужен Node.js 20 или новее. Установка npm-пакетов не требуется.

Обновить встроенный каталог из официальной спецификации:

```bash
node scripts/update-api-catalog.mjs --write-html
```

Сначала сформировать JSON для просмотра, не меняя приложение:

```bash
node scripts/update-api-catalog.mjs --output catalog.json
```

Использовать сохранённый снимок OpenAPI:

```bash
node scripts/update-api-catalog.mjs --input openapi.json --write-html
```

Генератор сохраняет источник, время снимка и SHA-256. Он обновляет каталог и шаблоны, но изменение формата ответа может потребовать отдельного изменения загрузчика и интерфейса.

## Проверка

```bash
node --test tests/*.test.*
```

Тесты используют синтетическое меню и изолированное выполнение JavaScript. Они не используют учётные данные и не обращаются к ресторанному API. Проверяются структура каталога, меню v3, отдельные размещения и размеры, наследование модификаторов, состав заказа, шаблоны редактора и смена контекста организации.
